## 4. 输入配置详解（每个字段做什么）

### 4.1 机翼配置（vehicles）

文件示例：`specs/vehicles/trapezoid_doublewedge_t0p034_sweep34.yaml`

重要字段：

- `planform.b_half_m`：半展长  
- `planform.c_root_m / c_tip_m`：根弦 / 梢弦  
- `planform.sweep_le_deg`：前缘后掠角  
- `leading_edge.rn_m`：前缘半径（<=0 表示尖前缘）  
- `airfoil.path`：翼型 `.dat` 文件路径  
- `surface.emissivity`：表面发射率  

### 4.2 工况配置（cases）

文件示例：`specs/cases/doc_ma5_alpha0_15_h30km.yaml`

关键分组：

1) 飞行条件  
- `fixed.h_m`：高度（m）  
- `theta_bounds`：Ma 和 alpha 的范围  

2) 气体模型  
- `gas.gamma`  
- `gas.R_J_per_kgK`  

3) 大气模型  
- `atmosphere.model`：如 `ussa1976`  

4) 黏度模型  
- `viscosity.model`：如 `sutherland`  
- `mu_ref_Pa_s / T_ref_K / S_K`  

5) 转捩约束  
- `transition_x_over_c`：该位置之前不允许转捩  

6) 壁温模型  
- `wall.model`：如 `fixed_temperature`  
- `wall.temperature_K`：固定壁温值  
- `tw_model.type`：`radiative_equilibrium` 或 `transient_balance`  
- `tw_model.sigma`：斯特藩常数  

7) 参考焓法配置  
- `lf_qw_model.pr`：Pr 数  
- `lf_qw_model.cp_J_per_kgK`：定压比热  
- `lf_qw_model.edge_model`：外缘链路与公式  

### 4.3 采样配置（sampling）

文件示例：`specs/sampling/engineering_full_wing_surface_grid_81x41.yaml`

核心字段：

- `mode`：`full_wing_surface_grid` 或 `root_windward_chord_line`  
- `x_over_c.start/end/n`：弦向采样  
- `y_over_b.start/end/n`：展向采样  
- `concat_order`：输出拼接顺序  
- `point_order`：数组展平顺序  

2D 输出数组的展平顺序是 **y 方向先、x 方向后**。  
前 `nx` 个点是根部 `y/b=0`。

## 6. 输出文件详解（你看见的每个键代表什么）

### 6.1 summary.json

你最常用的键：

- `inputs`：运行参数  
- `resolved_paths`：输入文件实际路径  
- `vehicle / case / sampling`：解析后的配置  
- `outputs_available`：此次输出的数组名称  
- `warnings_count`：告警数量  
- `freestream`：来流状态  

### 6.2 fields.npz

核心数组字段：

- `q_w`：迎风面热流  
- `q_l`：背风面热流  
- `Tw_w`：迎风壁温  
- `Tw_l`：背风壁温  
- `w_tr`：转捩权重  
- `re_edge`：外缘 Re_x  
- `re_tri`：转捩判据 Re  

瞬态模式在特定条件下可能额外输出：

- `t_s`  
- `Tw_w_time`  
- `q_w_time`

## 7. 运行时数据流（一步一步走）

### 7.1 入口脚本流程

`scripts/run_case_rem.py` 的流程是：

1) 解析命令行  
2) 创建 `WingLowFidelitySolver`  
3) 调用 `compute_snapshot()`  
4) 写 `summary.json`  
5) 写 `fields.npz`  
6) 尝试画图  

### 7.2 求解器内部流程

`WingLowFidelitySolver.__init__()`：

- 读取 YAML  
- 构造 `VehicleSpec/CaseSpec/SamplingSpec`  
- 生成采样网格  
- 读取翼型几何  
- 创建气体模型  

`WingLowFidelitySolver.compute_snapshot()`：

- 按展向逐条计算  
- 根据 `tw_model.type` 走不同壁温模型  
- 计算 `q_w/q_l/Tw_w/Tw_l`  
- 计算诊断 `re_edge/re_tri/w_tr`  
- 展平成数组并保存到 `last_fields`

## 11. 常见问题与解决办法

### 11.1 ModuleNotFoundError

确保你在项目根目录运行：

```bash
python scripts/run_case_rem.py ...
```

### 11.2 没有图像输出

可能未安装 matplotlib，或使用了 `--no_plots`。  
安装 matplotlib 或移除 `--no_plots` 即可。

### 11.3 壁温不变化

若 `case_spec.tw_model.type` 不是 `radiative_equilibrium` 或 `transient_balance`，  
求解器会走固定壁温模式，Tw 会保持常数。

### 11.4 前缘尖峰

若 `rn_m <= 0` 且 `x/c` 包含 0，前缘处热流会非常尖。  
做法：提高 `x_over_c.start` 或设置合理前缘半径。
