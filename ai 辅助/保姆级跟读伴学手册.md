# 参考焓法工程代码：保姆级跟读伴学手册

这一份是“你现在就能照着做”的陪读版，不需要你有基础。

---

## 1. 跟读准备清单（开始前确认）

- 能在终端里执行 `python -V`  
- 能在根目录看到 `scripts/` 和 `src/`  
- 能运行一次最小命令并生成 `runs/my_run/`  

---

## 2. 跟读方式（每一步都有动作）

每个步骤固定做三件事：

1) 打开指定文件  
2) 找到指定位置  
3) 写下“输入是什么、输出是什么、它解决什么问题”  

你只要照做，哪怕不懂公式，也会越来越清楚。

---

你现在不需要理解，只要知道这些文件存在。

## 4. 第 1 天：跑通并学会读输出

目标：跑通一次并知道输出在哪儿。

步骤：

1) 运行命令  

```bash
python scripts/run_case_rem.py --mach 5 --alpha 0 --run_dir runs/my_run
```

2) 打开 `runs/my_run/summary.json`  
3) 找到 `inputs`，确认你的 `mach` 和 `alpha`  
4) 找到 `outputs_available`，记下有哪些输出数组  
5) 打开 `runs/my_run/fields.npz`，用下面脚本打印最简单的统计  

```python
import numpy as np

z = np.load(r"runs/my_run/fields.npz")
Tw_w = z["Tw_w"].reshape(-1)
q_w = z["q_w"].reshape(-1)

print("Tw_w:", Tw_w.min(), Tw_w.max(), Tw_w.mean())
print("q_w :", q_w.min(), q_w.max(), q_w.mean())
```

你现在至少能回答：

- 输出在哪里  
- 输出有哪些字段  
- 每个字段有没有数值

## 5. 第 2 天：从入口脚本跟读一次

目标：理解入口脚本每一步做了什么。

打开 `scripts/run_case_rem.py`：

1) 找到 `argparse` 区域，记录所有参数名  
2) 找到创建 `WingLowFidelitySolver` 的位置  
3) 找到 `compute_snapshot()` 调用  
4) 找到 `summary` 字典  
5) 找到 `np.savez_compressed`  

写下这句话：

“入口脚本做的事 = 读参数 → 调求解器 → 保存 summary → 保存 npz → 尝试画图”

---

## 6. 第 3 天：跟读求解器初始化

目标：理解求解器一开始做了什么准备工作。

打开 `src/ref_enthalpy_method/solver.py`，找到 `__init__()`：

1) 看到 `load_yaml` 就记下：这一步在读配置  
2) 看到 `VehicleSpec/CaseSpec/SamplingSpec` 就记下：这一步把 YAML 转成对象  
3) 看到 `make_sampling_grids` 就记下：这一步生成采样网格  
4) 看到 `load_airfoil_dat_geometry` 就记下：这一步读取翼型几何  
5) 看到 `make_perfect_gas_thermo` 就记下：这一步准备气体模型  

写下这句话：

“求解器初始化就是把输入都变成可计算的对象。”

---

## 7. 第 4 天：跟读主计算流程

目标：理解 `compute_snapshot()` 的大体结构。

打开 `compute_snapshot()`：

1) 找到 `tw_type`，写下它控制哪种壁温模型  
2) 找到 `for j in range(self.ny)`，写下：它在做展向循环  
3) 找到 `q_w_list / q_l_list / Tw_w_list / Tw_l_list`  
4) 找到 `w_tr / re_edge / re_tri` 这一段  
5) 找到 `self.last_fields.update(...)`  

写下这句话：

“compute_snapshot = 按展向逐条计算 → 生成 q/Tw → 计算诊断 → 展平输出。”

---

## 8. 第 5 天：跟读迎风热流公式

目标：知道 q_w 是怎么从公式变成代码的。

打开 `heatflux/windward.py`：

1) 找到 `eckert_reference_enthalpy()`  
2) 找到 `windward_ref_enthalpy_branches()`  
3) 看看里面的 `q_lam` 和 `q_turb`  

写下这句话：

“迎风热流 = 层流分支 + 湍流分支，再根据转捩权重混合。”

---

## 9. 第 6 天：跟读转捩判据

目标：知道转捩权重从哪里来。

打开 `aero/transition.py`：

1) 找到 `transition_reynolds()`  
2) 读公式形式  
3) 回到 `solver.py`，找到 `w_tr` 计算段  

写下这句话：

“转捩权重 = 比较 re_edge 和 re_tri 的结果。”

---

## 10. 第 7 天：做一次小实验

目标：验证输入能影响输出。

实验步骤：

1) 把 `--alpha 0` 改成 `--alpha 5`  
2) 重新运行  
3) 比较两次 `summary.json` 中 `summary_Tw_w` 和 `summary_q_w`  

你应该能发现：Tw 或 q 有明显变化。
